# AI ChatBot with Claude

A desktop chatbot application built with Python and Tkinter, powered by Anthropic's Claude AI API. Features real-time streaming responses and a modern dark-themed UI.

## Features

- 🤖 **AI-Powered Conversations** - Uses Claude 3 Sonnet for intelligent responses
- ⚡ **Real-time Streaming** - See responses as they're generated
- 🎨 **Modern Dark Theme** - Easy on the eyes with a sleek interface
- 💬 **Conversation History** - Maintains context throughout the chat
- 🧹 **Clear Chat Option** - Reset conversation with one click
- ⌨️ **Keyboard Support** - Press Enter to send messages
- 🔄 **Threaded Processing** - UI remains responsive during API calls
